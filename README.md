# 英语语境学习系统

> ⚠️ **本仓库及全部资源仅供个人学习使用,请勿公开传播、二次分发或用于任何商业用途。**

从零基础到考研英语的分级语境学习站:文章精读 + 情景对话 + 听力 + 语法课 + 真题,五阶段渐进(S1 入门 → S4 考研 → S5 雅思),词库 9251 词、词典 8678 词、NCE/外刊/TED 资料库与考研/CET6 真题全部内嵌,开箱即用。

## 下载(只用下这两个)

到 [**Releases**](../../releases/latest) 页面:

| 文件 | 必须吗 | 内容 |
|---|---|---|
| `english-app-*-win64.zip`(18MB) | **必须** | 主程序 exe + 词库数据库 |
| `english-app-audio-*.zip`(800MB) | 建议 | 全部离线语音(1.5 万条:单词/课文/对话/听力) |

只下主包也能用,朗读走浏览器合成音;装语音包后为预生成自然音。

## 使用(三步)

1. 解压主包到任意位置(如 `D:\english-app`),双击 `english-app.exe`,浏览器自动打开(默认 `http://127.0.0.1:8787`,端口被占自动换,以窗口显示为准)
2. 语音包(可选):解压到 exe **同级目录**,得到 `audio_assets\` 文件夹,重启程序自动识别
3. 用完直接关窗口

## 说明

- **进度**:保存在自己电脑的 `data\user_learning.db`,换电脑备份整个文件夹即可
- **AI 功能**(可选):设置页填自己的 API Key(推荐 DeepSeek / 智谱,存本机浏览器),不填不影响其他功能
- **语音模型**:不装语音包时,首次朗读会联网下载浏览器语音模型(约 60MB),之后离线可用
- **端口**:默认 8787,被占用自动顺延;也可 `english-app.exe -port 9000` 指定
- 内置真题/词库数据**仅供个人学习,请勿公开传播**

## 从源码构建(开发者)

```bash
npm install && npm run dev          # 前端开发(127.0.0.1:5273)
build_app.bat                       # 打包单文件 exe(需 Node + Go)
```

技术栈:React + Vite + TypeScript,Go 单文件伴生服务(SQLite 词库/音频流/进度同步)。
